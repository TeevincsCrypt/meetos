# Demo script (≤ 3 minutes)

Use a desktop Chrome with built-in AI available (Settings → AI & privacy should say
"On-device model ready"), signed into a real Firebase project.

| Time | Action | What to point out |
|---|---|---|
| 0:00 | Landing page → **Get started** → sign in with Google | Value prop: meetings → work getting done |
| 0:15 | Onboarding → **Create demo workspace** | Clearly labelled sample data; nothing pre-analysed |
| 0:25 | Sidebar pill: **On-device AI ready** | Real capability check, not a static label |
| 0:30 | Meetings → *Beta launch planning (sample)* → **Analyse** | Part-by-part progress, each tagged **On this device** |
| 0:50 | Done summary: commitments, decisions; "N items discarded — evidence not found" | Grounding: nothing un-quoted is saved |
| 1:00 | Decisions tab: "Agreed by Maya Chen, Priya Raman, Daniel Okafor", quote, alternatives | Never manufactured consensus |
| 1:10 | Commitments: owners, deadlines from spoken words ("before Friday") | "I" resolved to the speaker |
| 1:20 | Open *Beta launch weekly sync (sample)* → **Analyse** | "3 updates to earlier commitments" |
| 1:35 | Commitments → *Finish the landing page* | **Commitment Graph**: Origin → Follow-up 1, "Deadline moved", quotes on the timeline |
| 1:55 | *Send final onboarding mockups* → "A later meeting says this is done. Confirm?" → **Yes** | AI never completes tasks; rules enforce it |
| 2:10 | Decisions → $24 decision → **This replaces "Beta price is $19"** | Decision memory tracks changes |
| 2:20 | Memory → "What did we decide about beta pricing?" | Cited answer, sources with meeting + date, **In the cloud** badge |
| 2:35 | Prepare → *Beta launch review* → **Generate** → Save agenda | Briefing from real records |
| 2:45 | Execution | Real metrics, honest "needs 3+ completed" for averages |
| 2:55 | Settings → AI & privacy: switch to **On-device only** | Privacy as a feature |

Fallback demo: in a browser without built-in AI, the same flow shows **In the cloud** on every
result — the labels always reflect what actually ran.
